# Support

This is a community open-source research project, not an official Microsoft support channel.

Use GitHub Issues for:

- benchmark proposals;
- reproducibility problems;
- tooling bugs;
- documentation gaps;
- sanitized benchmark result submissions;
- requests for additional test scenarios.

Before opening an issue:

1. search existing issues;
2. identify the benchmark or tool involved;
3. include the smallest reproducible example;
4. remove organization, tenant, environment, user, and customer identifiers;
5. do not include credentials or private data.

Questions that require access to a private tenant or production environment cannot be investigated from this repository alone.
