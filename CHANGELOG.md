# Changelog

All notable repository-level changes are documented here.

## Unreleased

- Real runtime benchmark measurements remain community-driven and are not fabricated by repository tooling.

## 1.0.0-public-baseline — 2026-10-03

### Added

- B001–B010 benchmark definitions and raw-result schemas.
- Evidence model from L0 proposal through L4 cross-environment validation.
- Public anonymization standard.
- Community validation process.
- Canvas App benchmark-runner build specification.
- Generic Dataverse benchmark tables and optional bootstrap scripts.
- Power Apps Live Monitor and `Trace()` capture guidance.
- Deterministic synthetic dataset generator.
- Benchmark result validator and statistical summarizer.
- Python and PowerShell CI validation.
- Public-only project model with no maintainer tenant dependency.

### Changed

- Removed maintainer-side Microsoft Entra / Dataverse CI authentication.
- Reframed real Power Platform validation as contributor-owned, sanitized evidence.
